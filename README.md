A demonstration repository for the **MATLAB Agentic Toolkit** — connecting Claude Code (AI coding agent) to MATLAB through the Model Context Protocol (MCP).

## What Is This?

This repo provides setup guides and demo scripts for teams who want to use Claude Code with MATLAB. Once configured, Claude can run MATLAB code, design filters, process images, write and run tests, and more — all from a conversational interface.

## Quick Start

See the full setup guide: [TEAM_SETUP_GUIDE.md](./TEAM_SETUP_GUIDE.md)

### What You'll Need
- MATLAB R2020b or later (tested with R2026a)
- Windows 10/11 (x64)
- An Anthropic account (claude.ai)

### Setup Overview
1. Install Node.js
2. Install Claude Code CLI (`npm install -g @anthropic-ai/claude-code`)
3. Download and configure the MATLAB MCP Server
4. Install MATLAB skills as Claude Code plugins
5. Launch Claude Code and verify the MATLAB connection
